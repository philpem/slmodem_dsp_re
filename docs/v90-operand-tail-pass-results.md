Playbook transfer: inspect the complete target body before treating a missing
instruction in an excerpt as a source discriminator. Opcode counts cannot
recover evaluation order, but are a cheap positive/refutation control for
claims that an operation is absent. Unique-symbol census membership likewise
does not grade every repeated template instance; an object-level shortlist
must grade its actual body. Preserve false nominations and exclude them from
recovery conclusions instead of hiding them in a negative matrix total.
